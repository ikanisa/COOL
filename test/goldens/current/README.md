# Current implementation regression captures

These captures use actual synthetic Collect widgets with the selected Inter and Material fonts. They are regression evidence for intentional current implementation behavior. The 15 October 2026 refresh preserves recorded-contribution wording, exact values, current navigation and the public website content. The affected member and desktop renderings were visually inspected before regeneration.

All thirteen historical captures and their original `GOLDEN_MANIFEST.sha256` remain unchanged in `../baselines`. Current comparisons use this directory so historical images do not require restoration of superseded wording or layout. No comparison tolerance is relaxed. A normal run without `--update-goldens` must validate a generated baseline before its regression result is accepted.

These synthetic captures are not the shipping cookie Admin browser, installed-device evidence, a Revolut comparator or an assertion of complete visual fidelity. The sole product design authority remains Revolut Design from Jean Bosco Skills, `revolut-design@jean-bosco-skills`. The current visual manifest records PNG byte identities; hosted role/state, accessibility and device acceptance remain separate.
