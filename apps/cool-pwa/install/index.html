Install and distribution readiness

The manifest includes shortcuts, screenshots, maskable icons, a share target, and standalone launch behavior. This page explains how that maps to browsers and store packaging.

Chromium browsersDeferred prompt
  • Install prompt appears only after engagement proves value.
  • Maskable icons and screenshots improve install UI quality.
  • App shortcuts expose Home, Groups, MoMo, and Alerts.
iOS SafariGuided
  • No automatic install prompt exists.
  • The PWA guides users through Share → Add to Home Screen.
  • Installed iOS PWAs can participate in push flows on modern Safari.
