Eight pillars, implemented as product behavior

The new PWA is intentionally static-first and app-shell driven, so it can pass performance, offline, SEO, installability, and security expectations at the same time.

Performance

Static HTML, preloaded local fonts, low-JS pages, and cached data endpoints.

Installability

Maskable icons, screenshots, shortcuts, deferred prompts, and iOS coach marks.

Offline

Precached shell routes, network-first data, offline fallback, and queued replay.

Security

Strict hosting headers, no mixed content, clean routes, and passkey-capable UI.

Accessibility

Skip link, keyboard-friendly navigation, touch targets, reduced motion, and dark mode.

Engagement

Contextual notification opt-in, Web Share, badge counts, and install funnel tracking.
