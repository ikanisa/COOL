# Collect Screen Redesign Plan

## App Shell

Use exactly three primary mobile tabs: Home, Groups, and Settings. Secondary
screens live under those sections.

## Onboarding And Profile

WhatsApp login accepts international numbers. Profile captures the 6-digit
Collect ID generated by the platform and the user's MoMo number. The app does
not ask for real names, display names, avatars, or anonymity preferences.

## Home

Home shows the member's groups, pending payment intents, confirmed support, SMS
sync state, and fast entry points into group workflows.

## Groups

Group creation is simplified to group name, optional description, and receiver
MoMo synced from the creator profile with an edit option. Android creation
triggers SMS access consent; iPhone creation is disabled and shows
`group creation is available only on Android`.

## Contribution And Payment

Contribution starts with amount and a Contribute button. The app creates a
payment intent tied to group, user, Collect ID, amount, and receiver MoMo, then
opens the MoMo USSD dialer through `tel:`. Confirmation happens only through
MoMo SMS parsing and Supabase allocation.

## Share And Invite

Groups can be shared by link, QR code, chat apps, SMS, and deep links. Receiver
MoMo details remain inside the contribution/payment-intent flow.

## Ledger And Admin

Ledger shows confirmed automated allocations. Admin monitors Groups, Members,
Payment intents, SMS parsing, Allocations, Exceptions, Ledger, Receivers, SMS,
Audit logs, Settings, Feature flags, System health, and Admin users.
