# Collect Screen Redesign Plan

## App Shell

Use a calmer bottom navigation with tokenized icons, labels, surfaces, and selected state. Keep Home, Collections, Public, and Settings as the primary mobile navigation.

## Onboarding And Profile

Welcome/WhatsApp login and OTP entry should explain Rwanda phone login, CAPTCHA when enabled, and the path to profile setup. Profile setup should clarify public ID, display name, MOMO storage, avatar visibility, and anonymity default.

## Home

Show total raised, active collections, pending payment intents, unallocated review count, receiver mode state, and recent collections. Keep create and public directory actions visible.

## Collections

Cards show title, category, privacy/public status, raised amount, progress, supporter count, and recurring status. Empty state explains private-first collection creation.

## Contribution And Payment

Contribution amount and anonymity choice appear before optional sender phone. MOMO instructions show amount, receiver label/number, contribution code, status, expiry, direct payment copy, and a confirmation action. Payment status must support pending, matched, confirmed, needs review, and expired labels.

## Share And Invite

Share uses QR plus safe link text. Receiver MOMO details stay hidden until contribution. Invite supports phone or 6-digit Collect ID without contact-book access.

## Ledger And Admin

Ledger separates confirmed contributions from unallocated review. Admin uses dense approval and review cards with status, amount, confidence, and explicit action reasons.

## Receiver Mode

Receiver mode requires explicit consent, shows internal flag state, monitored number context, secure copy, manual paste fallback, and sync feedback.
