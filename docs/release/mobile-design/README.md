# Selected historical design evidence

This directory retains three recovered evidence files: the owner-annotation
record, the original screenshot metadata index, and the surface-comparison
ledger. They describe dated product observations and private reference file
hashes. The owner-selected `revolut-design` skill is the sole design authority;
these files do not define a second visual system or approve a current build.

The referenced private screenshots are not copied into this repository.
Original metadata may name locations that are absent or stale; inspect and
hash-read the actual source image before using it. The comparison ledger's
`unverified` status remains open. Historical widget baselines are separately
documented in `test/goldens/README.md` and are regression evidence only.
