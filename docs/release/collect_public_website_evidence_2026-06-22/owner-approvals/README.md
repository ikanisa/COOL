# Owner Approval Evidence

Attach owner approvals or explicit deferrals here.

Accepted files:

- `collect-product-proof.md`
- `collect-product-proof-deferral.md`
- `translation-approval.md`
- `visual-approval.md`
- `bing-deferral.md`
- `play-console-deferral.md`

Templates are provided with `.template.md` filenames. They do not satisfy the
completion gate until copied to the accepted filename and completed with real
approval or deferral details.

Each approval should include:

- owner name and role;
- approval date;
- exact approved item;
- any corrections or conditions;
- expiry or review date where claims can become stale.

No partner, regulator, customer, credit, insurance, or product traction claim
should be published without approval evidence here.

The completion gate rejects short placeholder files and files containing
`pending`, `todo`, or `tbd`. Use explicit `approve` or `defer` language as
applicable.
