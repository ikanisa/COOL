# Play Console Evidence

Attach Play Console privacy URL/listing update evidence here if the owner
approves a store update or resubmission.

Accepted artifacts:

- `privacy-url-update.md`
- `privacy-url-update.png`

If the owner decides no Play Console action is required now, record that in:

- `../owner-approvals/play-console-deferral.md`

No Play Console submission should be made without explicit recorded owner
approval.

Markdown evidence must include owner/date fields and explicit `approve` or
`defer` language. Placeholder files do not satisfy the completion gate.
