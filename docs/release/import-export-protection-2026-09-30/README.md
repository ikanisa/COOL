## Existing safeguards and their limits

- Names: 2–120 Unicode code points, control rejection and leading `=`, `+`, `-`, `@` rejection after normalization in browser review and Edge candidate policy. XLSX formula cells/features are rejected before the Excel document is built. The plus in canonical `+250...` phone text is expected input, not proof that spreadsheet outputs are escaped.
- Upload/text: 512,000 UTF8 bytes for text/CSV/TXT; 5MiB binary source; 8MiB Edge request envelope; up to 500 preview members. Commit group capacity is a separate smaller server policy, not the preview limit.
- Workbook: 64 ZIP entries, 8MiB total expanded bytes, 2MiB individual entry, 10 sheets, 32 columns, bounded member/header rows and XML events/depth/cells/strings/styles; bounded actual inflate output and canonical stored ZIP reassembly avoid trusting compressed size claims. Historical 57 parser/preflight passes and five CSV/TSV regressions are scoped local evidence.
- Resource accounting: SQL policy records actor/global requests, bytes, AI cost units and active reservations before work; source/digest/session/request receipt is strict. Edge/provider mocks verify contracts, not actual budget race behavior or vendor billing. Root SQL acceptance owns those facts.
- Minimization: browser bookmarks have only references/digests; file bytes, pasted names/numbers, reason and edited rows are not persisted there. SQL recovery expiry hides private editor/intent payload; owner-only bounded purge deletes expired recovery payload while deliberately preserving source/review/commit audit provenance.
- Redaction: Admin safe errors emit fixed messages; current app logger call reports environment name only. Platform audit uses masked phone. Raw SMS becomes available only through separate audited reveal. This does not prove all Edge/native/server/access logs are covered.
- XLSX trust: source and browser-derived TSV are separately hashed and UI explicitly states server does not verify TSV against workbook cells. Human review remains required; do not relabel this as server workbook ground-truth verification.
