# Collect Runtime Fonts

Place only approved or repo-approved Revolut-aligned font files in this
directory.

Expected runtime inputs:

- Approved primary UI font files.
- Approved display font files for large heading and money hierarchy.
- Weight/style variants required by `CollectTypography`.
- License or approval metadata stored in docs, not secrets.

Current status: installed with Inter for `Collect Runtime` and Inter Display for
`Collect Display`. See `PROVENANCE.md` for source, license, and replacement
rules.
